🚀 Deployment Guide - Get Your Live Website Running

The app is ready! Follow these steps to deploy it live:

Step 1: Get Your Gemini API Key

  1. Visit https://aistudio.google.com/app/apikey
  2. Sign in with your Google account
  3. Click "Create API Key"
  4. Copy the generated key (keep it safe!)

Step 2: Deploy on Render

  1. Go to https://render.com
  2. Click "Sign Up" (use GitHub for easy login)
  3. Click "New +" → "Web Service"
  4. Select "Connect a repository" and choose Shiva163-ya/CareerAi
  5. Fill in the configuration:
    Name: careerai Environment: Python 3 Region: Oregon (or nearest to you) Build Command: pip install -r careerai/requirements.txt Start Command: cd careerai && gunicorn app:app
  6. Click "Advanced" and add Environment Variable:
    Key: GEMINI_API_KEY Value: [Paste your API key from Step 1]
  7. Click "Create Web Service"
  8. Wait for deployment (2-5 minutes)
  9. Your app will be live at: https://careerai.onrender.com (or your custom name)

Step 3: Test Your Live App

  1. Once Render shows "Live", click the URL in the top left
  2. Your CareerAi app is now live!
  3. Try the Career Coach, Resume Analyzer, Coding Agent, and Mentor features

📌 Important Notes

  • Why not GitHub Pages? GitHub Pages only hosts static HTML/CSS/JS. Your CareerAi is a Python Flask app that needs a server.
  • Render is free: The free tier includes 0.5 GB RAM and automatic deployments from GitHub
  • Auto-restart: Your app will sleep after 15 mins of inactivity on free tier (wakes up when accessed)
  • Keep API key secret: Never commit your API key to GitHub. Always set it in the hosting environment.
  • Domain: You can add a custom domain in Render settings later
